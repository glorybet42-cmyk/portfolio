# Weather Telegram Bot

**Автоматический прогноз погоды в Telegram**

Бот работает на self-hosted n8n (Docker, Ubuntu). Каждое утро в 8:00 собирает данные с API, форматирует (температура, ветер, осадки) и отправляет пользователям.

## Технологии
- n8n (self-hosted)
- REST API
- Telegram Bot API
- Markdown

## Возможности
- Расписание (ежедневно в 8:00)
- Форматирование прогноза
- Поддержка нескольких пользователей
