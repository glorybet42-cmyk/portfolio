**Агент поиска вакансий**

Парсит вакансии, фильтрует через LLM (DeepSeek/ChatGPT), отправляет результаты в Telegram.

## Технологии
- n8n
- HTML Extract
- OpenRouter API (LLM)
- Telegram Bot API

## Возможности
- Парсинг вакансий
- Фильтрация по критериям
- Уведомления в Telegram

## Статус
Работает в личных целях.
