# Ceny24.by — двусторонний маркетплейс

Маркетплейс с геопоиском, чатом, пуш-уведомлениями и слепыми аукционами.

## Технологии
- Python 3.13
- Flask
- Flask-SocketIO (WebSockets)
- PostgreSQL
- Celery + Redis
- Docker
